About the tool

A private Apple Intelligence JSON report analyzer.

This browser-based viewer turns an Apple Intelligence JSON export into a readable report. It is designed for understanding model activity and the boundary between on-device processing and Private Cloud Compute without sending sensitive conversation data to a server.

Explore model activity

Review model names, versions, use cases, clients, execution environments, timestamps, and readable request excerpts.

Trace Private Cloud Compute

Correlate device requests with PCC records using shared identifiers, then inspect pipeline parameters, token intervals, and node health.

Understand the schema

See every observed path, value type, presence rate, and shape so the structure of the JSON export is easy to document or analyze.

Frequently asked questions

Before you open a report.

Does the Apple Intelligence report explorer upload my file?

No. The report is read and parsed in your browser tab. There is no upload endpoint, and the file does not need to leave your device.

What can I inspect in an Apple Intelligence JSON report?

You can inspect model requests, timestamps, use cases, model versions, request identifiers, Private Cloud Compute pipeline parameters, node state, token ranges, response excerpts, and a typed schema inventory.

What file format does the explorer accept?

The explorer accepts a JSON export containing Apple Intelligence request collections such as modelRequests and privateCloudComputeRequests.
